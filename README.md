# CodeAlpha Flashcard Quiz App

A simple and interactive Flashcard Quiz App developed as part of the CodeAlpha App Development Internship.

## Features

- 📚 Display flashcard questions
- 👁️ Show answers
- ⬅️ Previous and ➡️ Next navigation
- ➕ Add new flashcards
- ✏️ Edit flashcards
- 🗑️ Delete flashcards
- 📱 Mobile-friendly design

## Technologies Used

- HTML
- CSS
- JavaScript
